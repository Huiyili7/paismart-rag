# 操作系统

## 进程与线程
进程是资源分配的基本单位，拥有独立的地址空间。线程是 CPU 调度的基本单位，同一进程内的多个线程共享地址空间和资源。线程切换的开销通常小于进程切换。

## 死锁
死锁是指多个进程互相等待对方持有的资源而无法继续执行。产生死锁需要同时满足互斥、占有并等待、不可抢占和循环等待四个必要条件。破坏其中任一条件即可预防死锁。

## 虚拟内存与分页
虚拟内存让每个进程都以为自己拥有连续的大块内存。操作系统通过分页机制把虚拟地址映射到物理地址，并在物理内存不足时把暂时不用的页换出到磁盘。

## CPU 调度算法
常见的 CPU 调度算法包括先来先服务（FCFS）、最短作业优先（SJF）、时间片轮转（Round Robin）和优先级调度。时间片轮转通过为每个进程分配固定时间片来保证响应性。

## 文件系统
文件系统负责管理磁盘上数据的组织和存取。它通过目录结构、inode 和数据块来记录文件的元数据和内容，并提供按名存取的接口。
